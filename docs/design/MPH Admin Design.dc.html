1bStances on §6 — short version
1 Empty state — a proper first-run moment: what will appear here + the one next step. See 1e.
2 Project row — he scans for which job and is it visible; thumbnail + title + chip stay, meta recedes, controls drop to a second row at full width. See 1f.
3 Photos: rows, not grid — at 360px a 3-col grid leaves 104px cells; four 56px controls don't fit without overlays he can mis-tap. Rows keep, but photo-forward: 112px preview, cover pinned first. See 1j.
4 "Tee foto" — earns its place: second 56px button beside the picker, camera capture. String: „Tee foto".
5 Upload progress — one big count + one bar he can read at arm's length; per-photo detail only for the failures. See 1j.
6 Bottom bar — stays ink; gains the job's status line so the bar answers "what happens when I press this". See 1h.
7 Undo — not worth it: an 8s toast is exactly what dusty hands in daylight miss. The specific dialog + the „Võta kodulehelt maha" line already catch the real mistake. Keep deletion honest and permanent.
8 Keelevahetus (added) — ET/RU flag buttons in the admin header, overriding the brief's Estonian-only interface at the client's request. Needs a Russian admin string set alongside admin-text.ts; flags shown in the header below.
